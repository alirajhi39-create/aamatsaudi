# منصة درس «أئمة الدولة السعودية الثانية» التفاعلية

الدراسات الاجتماعية — الصف السادس الابتدائي — الوحدة الثالثة — الدرس الثامن.

واجهة React (Next.js App Router) بخطوط **Cairo** و**Tajawal** واتجاه **RTL**، وخلفية API تعمل كدوال Serverless على Vercel مع قاعدة بيانات PostgreSQL (Neon) عبر Drizzle ORM.

## التشغيل

```bash
npm install
npx drizzle-kit push   # إنشاء الجداول
npm run dev
```

### متغيرات البيئة

| المتغير | الوصف |
| --- | --- |
| `DATABASE_URL` | رابط PostgreSQL (Neon: `postgresql://...?sslmode=require`) |
| `TEACHER_PIN_OVERRIDE` | (اختياري) يتجاوز رمز المعلم الثابت في `src/lib/teacher-auth.ts` |
| `CORS_ORIGIN` | النطاقات المسموح بها مفصولة بفواصل، أو `*` (الافتراضي) |

## قواعد المنصة

- **فصل واحد فقط: 6/ب** — كل السجلات تُوحَّد تلقائياً إلى هذا الفصل (`src/lib/config.ts`).
- **لا يمكن تكرار الاسم** — فهرس فريد على `(class_name, name_key)` في `lesson_progress`؛ عند تسجيل اسم موجود يرد الخادم `409 NAME_TAKEN` ويظهر للطالب سؤال «هل أنت صاحب هذا الاسم؟» (يُرسل `confirmResume: true` للمتابعة). يُشترط اسم من كلمتين على الأقل ما لم يكن ضمن قائمة المعلم.
- **زر الاستماع/الإيقاف** داخل كل شريحة (تسجيل المعلم إن وُجد وإلا قراءة آلية عربية) مع زر كتم المؤثرات.
- **إعادة الدرس وزر الخروج**: بعد الشهادة يظهر للطالب «إعادة الدرس من البداية» (بالاسم نفسه، مع حفظ المحاولة السابقة للمعلم) و«خروج»، وزر خروج دائم في الشريط السفلي يحفظ التقدم قبل المغادرة.
- **تحديث تلقائي للوحة المعلم**: تبويب التقارير يتحدث كل 10 ثوانٍ (يتوقف عند إخفاء التبويب ويُحدَّث عند العودة)، مع مؤشر مباشر، إبراز الصفوف المتغيرة، وتنبيه عند دخول طالب جديد أو تقدمه، وزر لإيقاف/تشغيل التحديث.
- **تقرير PDF**: `/teacher/report` (تقرير الفصل مع صفحة لكل طالب) أو `?studentId=` لطالب واحد — زر «حفظ PDF / طباعة» يستخدم طباعة المتصفح (اختر «حفظ بصيغة PDF»).

## الصفحات

- `/` دخول الطالب (الاسم الثلاثي — الفصل ثابت 6/ب)
- `/teacher/report` تقرير PDF مرتب (ملخص، توزيع المستويات، كشف الدرجات، صفحات الطلاب)
- `/lesson` الدرس التفاعلي (20 شريحة بـ 18 استراتيجية تعلم: K-W-L، الخط الزمني، القراءة الموجهة، الأسئلة السابرة، السبب والنتيجة، القصة التفاعلية، فكّر-زاوج-شارك، الخريطة التفاعلية، بطاقات الاستكشاف، تحليل الأسباب، التصنيف، التعلم القيمي، ترتيب الأحداث، التفكير الناقد، الخريطة الذهنية، المطابقة، صواب/خطأ، الاختبار الختامي، بطاقة الخروج 3-2-1 + شهادة)
- `/teacher` لوحة تحكم المعلم (تقارير، قوائم الفصول وتثبيت الأسماء، إدارة الأصوات، التشخيص)

## واجهة برمجة التطبيقات (API)

جميع المسارات تدعم CORS و`OPTIONS` (preflight). العمليات الإدارية تتطلب الترويسة `X-Teacher-Pin`.

### `/api/progress` — تقدم الطلاب (`lesson_progress`)

| الطريقة | الوصف |
| --- | --- |
| `GET ?studentId=` | استئناف تقدم طالب |
| `GET ?class=٦/أ` / `GET` | قائمة الطلاب (فصل محدد أو الكل) مع ملخص |
| `GET ?diagnose=true` | الوضع التشخيصي: الاتصال بقاعدة البيانات، الجداول، البيئة، CORS |
| `POST` | حفظ/تحديث (upsert): `{studentId?, name, className, currentSlide, maxSlide, quizScore?, quizTotal?, quizSubmitted?, activities?, completed?}` — تُدمج الأنشطة (JSON) وتُحفظ أقصى شريحة |
| `PATCH` 🔒 | تعديل المعلم `{studentId, name?, className?, currentSlide?, quizScore?, lock?, resetActivities?}` — يثبّت الاسم/الفصل في `teacher_names` |
| `DELETE ?studentId=` / `?class=` / `?all=true` 🔒 | حذف السجلات (`&names=true` لحذف قائمة المعلم أيضاً) |

`POST /api/progress/restart` — `{studentId}` إعادة الدرس للطالب نفسه: تصفير الأنشطة والاختبار والعودة للشريحة الأولى مع أرشفة المحاولة السابقة في `activities.__history` (تظهر للمعلم في التفاصيل وتقرير PDF).

`POST /api/progress/login` — نقطة دخول الطالب: تُطابق الاسم مع قائمة المعلم (الأسماء المثبتة لا يمكن للطالب تغييرها) وتُعيد التقدم السابق.

### `/api/teacher/names` — قوائم المعلم (`teacher_names`)

`GET ?class=` (عام) · `POST {className, names[]}` 🔒 · `PATCH {studentId, name?, className?, locked?}` 🔒 · `DELETE ?studentId=|?class=|?all=true` 🔒

### `/api/sounds` — الأصوات المخصصة (`lesson_sounds`, BYTEA)

| الطريقة | الوصف |
| --- | --- |
| `GET` | قائمة الأصوات (بيانات وصفية فقط) |
| `GET ?key=xxx` | الملف الصوتي مع `ETag`, `Last-Modified`, `Cache-Control` ودعم `If-None-Match` / `If-Modified-Since` → `304` |
| `GET ?key=xxx&meta=true` | البيانات الوصفية لمفتاح واحد |
| `POST` 🔒 | رفع `multipart/form-data` (`key`, `file`) أو JSON (`dataBase64`) — الحد الأقصى **4 ميجابايت** (قيود Vercel) |
| `DELETE ?key=xxx` 🔒 | حذف صوت (أو `?all=true`) |

المفاتيح: `click`, `correct`, `wrong`, `flip`, `success`, `celebrate`, `welcome`, و`narration-1` … `narration-20` للتعليق الصوتي على الشرائح. عند عدم وجود صوت مخصص يُستخدم صوت مولَّد (Web Audio) أو قراءة آلية عربية.

## النشر على Vercel + Neon

1. أنشئ قاعدة بيانات على Neon وانسخ رابط الاتصال (يفضَّل الرابط الذي يحتوي `-pooler`، وينتهي بـ `?sslmode=require`).
2. في Vercel: **Settings → Environment Variables** أضف `DATABASE_URL` = رابط Neon (لجميع البيئات)، ثم أعد النشر (Redeploy).
3. **لا حاجة لتشغيل أي ترحيل يدوي**: عند أول طلب ينشئ التطبيق الجداول تلقائياً (`src/db/ensure-schema.ts`)، ويمكن تشغيل ذلك يدوياً بفتح `https://<موقعك>/api/setup`.
4. (اختياري) للدفع اليدوي من جهازك: `DATABASE_URL="..." npx drizzle-kit push --config drizzle.config.prod.ts`.

### استكشاف الأخطاء بعد النشر

| الرسالة | السبب | الحل |
| --- | --- | --- |
| لم يتم ضبط رابط قاعدة البيانات | `DATABASE_URL` غير موجود في Vercel | أضفه ثم أعد النشر |
| الرابط يشير إلى جهاز محلي (127.0.0.1) | بقي الرابط المحلي من ملف `.env` | ضع رابط Neon في إعدادات Vercel (يتجاوز `.env`) |
| جداول قاعدة البيانات غير مكتملة | قاعدة جديدة | تُنشأ تلقائياً — أو افتح `/api/setup` |
| مشكلة SSL | الرابط بدون `sslmode` | يُفعَّل SSL تلقائياً لأي مضيف غير محلي؛ تأكد من الرابط |
| انقطع الاتصال مؤقتاً / حدث خطأ أثناء التعامل مع قاعدة البيانات | اتصال ميت بعد سكون Neon أو قيد مفقود | يُعاد الطلب تلقائياً على اتصال جديد ويُصلح المخطط ذاتياً؛ راجع «اختبار الكتابة» في التشخيص |

للفحص الشامل: `GET /api/progress?diagnose=true` — يفحص الاتصال، الجداول **والقيود/الفهارس**، ويُجري **اختبار كتابة حقيقياً** (إنشاء سجل طالب ثم التراجع عنه) ويعرض قائمة `problems` بالعربية مع إحصاءات إعادة المحاولة. واجهة الطالب تعرض رسالة ودّية مع «تفاصيل تقنية للمعلم» بدل نص SQL الخام.

### المتانة على Serverless
- `pool.query` مغلّف بإعادة محاولة تلقائية (حتى 4 مرات مع تأخير متزايد) للأخطاء العابرة: اتصال ميت بعد تجميد الدالة أو سكون Neon، استيقاظ القاعدة، كثرة الاتصالات… (`src/db/transient.ts`).
- أخطاء المخطط (42P01/42703/42P10) تستدعي الإصلاح الذاتي ثم تُعاد مرة واحدة.
- الإصلاح الذاتي يعمل داخل معاملة واحدة بقفل `pg_advisory_xact_lock` (آمن مع PgBouncer/‏pooler).

## الأنشطة بالاختيار والسحب

- جميع الأنشطة التي كانت كتابية أصبحت **اختيارات جاهزة**: K-W-L، نشاط ١ (فكّر–زاوج–شارك)، نشاط ٢ (النتائج + إكمال الجملة)، تأمل القيم، وبطاقة الخروج 3-2-1 مع تقييم ذاتي.
- ترتيب الأحداث يتم **بالسحب والإفلات** (فأرة/لمس) مع أسهم احتياطية لإمكانية الوصول.
- تُعرض إجابات الطالب (✔/✘) في لوحة المعلم وتقرير PDF عبر `src/lib/activity-summary.ts`.

## الخريطة التفاعلية وخلط الإجابات

- الخريطة (`src/components/lesson/MapSlide.tsx`) مرسومة بـ SVG من إحداثيات جغرافية حقيقية لسواحل شبه الجزيرة (مُسقطة على 1200×1000) مع بحار متدرجة، سلاسل جبلية، مفتاح، بوصلة، ٦ دبابيس للمناطق و٦ مواقع وردت في الدرس (الرياض، الحُلوة، المُلَيْداء، حائل، الكويت، مصر).
- **تُخلط الإجابات عشوائياً في كل مرة** تُفتح فيها الشريحة (وفي كل إعادة محاولة للاختبار): خيارات الاختبار الختامي، أسئلة التحقق، السبب والنتيجة، المطابقة، التصنيف، بنك الخريطة الذهنية، ترتيب الأحداث، صواب/خطأ، والأنشطة الاختيارية — عبر `src/components/lesson/useShuffle.ts`. تُحفظ الإجابات بمعرّفها الأصلي فلا يتأثر التقرير.
